SessionViewer renders a recorded AI coding-agent session (the captain `pkg/ai/history` JSON schema — Claude Code / Codex transcripts) as a vertical action log. Each entry sits on a tone-colored icon disc from the Flanksource "Agent Action Icons" set; user prompts/selections are right-aligned like a chat. Shell commands render inline as bash blocks and file ops as their cwd-relative path — the icon carries the verb. Tool responses expand behind a chevron, rendered bare (no panel chrome). The "3-dot" menu mirrors `captain history` filtering — toggle density and hide categories, tools or sources.
